Cotes de Polymarket, Kalshi et Manifold. Un robot GitHub Actions (hors France) interroge les API toutes les 12 h et écrit data.json dans ce dépôt ; cette page lit ce fichier — aucun appel externe depuis ton navigateur, donc rien n'est bloqué. Le bouton Rafraîchir recharge data.json (il change quand le robot repasse).
Polymarket et Kalshi sont en dollars réels ; Manifold est en monnaie fictive (Ṁ), à lire comme un sondage. Un pourcentage est la probabilité implicite « Oui ». Les onglets montrent le haut du volume / intérêt ouvert par catégorie (instantané collecté). La recherche interroge le catalogue en direct : Polymarket (via le proxy jina) et Manifold en temps réel, Kalshi sur l'instantané (il n'a pas de recherche texte et couvre peu la politique hors USA). Cotes indicatives — pas un conseil d'investissement.
